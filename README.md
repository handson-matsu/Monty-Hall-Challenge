# モンティ・ホール実験室

HTML / CSS / JavaScriptだけで動く、日本語の教育用Webアプリです。外部ライブラリ、外部フォント、ビルド、通信は不要です。

## 起動

`index.html` をブラウザで開いてください。

## 機能

- **体験モード**：3〜20個のドアから選択し、司会者がハズレを開けたあと、変更するか決めます。
- **連続チャレンジ**：戦略と10・50・100・500・1000回を選択。毎回最初のドアを選ぶだけで、650ミリ秒後に判定し、結果を1秒表示して次へ進みます。
- **一括シミュレーション**：100〜100万回を実行し、両戦略の当たり・ハズレ・勝率・理論値を比較します。
- CSS棒グラフ、確率の解説、キーボード操作、画面読み上げ用通知、スマートフォン・タブレット対応。

## 記録とルール

記録はモードとドア数ごとにページ内で保持します。再読み込みで消えます。一括シミュレーションは実行ごとに結果を置き換えます。「記録をリセット」は現在のモード・ドア数の記録だけを消去します。モードや設定の変更で進行中の試行・チャレンジは最初に戻ります。連続チャレンジの上部は今回の成績、下部は同じドア数での累計です。

司会者は当たりを知っていて、最初に選ばれていないハズレを必ず n−2 個開けます。最初の選択が当たりの場合、もう1つ残すドアはハズレの中からランダムに選びます。当たりは最終判定まで表示しません。

一括シミュレーションは毎回ランダムに当たりと初期選択を生成し、同じ試行に両戦略を適用します。そのため両戦略の当たり回数の合計は試行回数と一致します。理論値は変更しない場合 1/n、変更する場合 (n−1)/n です。

## GitHub Pagesへの公開

1. このフォルダのファイルをGitHubリポジトリにコミット・プッシュします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、公開するブランチの **/ (root)** を指定して保存します。

ファイルは相対パスで参照しているため、プロジェクト用Pagesでも動作します。公開操作自体はまだ行っていません。

## ファイル

- `index.html`：画面構造
- `style.css`：レスポンシブデザイン
- `logic.js`：ゲーム・シミュレーションのロジック
- `app.js`：画面操作と集計
- `tests/logic.test.cjs`：3〜20ドアの全当たり位置・全初期選択の検証と、固定乱数による確率検証

Node.jsがある環境では `node tests/logic.test.cjs` でロジックの検証を実行できます。アプリ利用時にNode.jsは不要です。
